# بسته تحویل به ChatGPT برای ساخت سریع طلاتا

این پوشه همه چیزی است که یک مدل برنامه‌نویس (ChatGPT، Codex یا هر عامل مشابه) برای ساخت نسخه ۱ طلاتا لازم دارد: قواعد ثابت، ترتیب کارها، مشخصات هر صفحه با همه حالت‌ها، نمونه API و چک‌لیست پذیرش. هر صفحه یک **مرجع ظاهری HTML** در `docs/design/reference-html/` و یک اسکرین‌شات در `docs/design/proposed/screenshots/` دارد.

## روش استفاده (برای مالک)

1. مخزن را به ChatGPT بدهید (اتصال GitHub یا آپلود zip). اگر فقط فایل می‌توانید بدهید، این‌ها را حتماً پیوست کنید: کل `docs/handoff/`، `docs/IMPLEMENTATION_GUIDE.md`، `docs/prompts/PHASE_1_MASTER_PROMPT.md`، `docs/design/contracts/`، `docs/design/tokens/` و `docs/design/reference-html/` صفحه‌های همان کار.
2. متن کامل `00_CHATGPT_SYSTEM_PROMPT.md` را در ابتدای گفت‌وگو (یا در Custom Instructions / Project Instructions) بگذارید.
3. کارها را **به ترتیب** از `01_BUILD_SEQUENCE.md` یکی‌یکی بدهید: متن کارت هر کار (مثلاً «T07») را کپی کنید. هر کارت می‌گوید کدام فایل‌ها را بخواند و کار کی تمام است.
4. پس از هر کار، خروجی را با بخش «تمام وقتی» همان کارت و `07_QA_CHECKLIST.md` بسنجید. اگر چیزی ناقص بود، همان کارت را با توضیح کمبود دوباره بدهید.
5. پالت، لوگو و toolkit نهایی هنوز تأیید نشده‌اند. ChatGPT با پالت ۱ و لوگوی ۱ و توکن‌ها می‌سازد؛ تغییر بعدی فقط توکن و فایل لوگو را عوض می‌کند.

## فهرست فایل‌ها

| فایل | محتوا |
| --- | --- |
| `00_CHATGPT_SYSTEM_PROMPT.md` | دستور ثابت برای مدل: نقش، stack، قواعد غیرقابل‌مذاکره، قالب خروجی |
| `01_BUILD_SEQUENCE.md` | ۲۳ کارت کار به ترتیب سریع‌ترین مسیر، هر کدام با ورودی، خروجی و معیار پایان |
| `02_SCREENS_MERCHANT.md` | مشخصات صفحات فروشگاه (موبایل و دسکتاپ) با همه حالت‌ها |
| `03_SCREENS_PUBLIC_PRINT_PAYMENT.md` | فاکتور عمومی، بررسی QR، چاپ A4، خرید پیامک و بازگشت از بانک |
| `04_SCREENS_ADMIN.md` | پنل مدیریت سرویس نسخه ۱ (۱۲ صفحه) با مجوزها و API |
| `05_STATES_AND_PATTERNS.md` | حالت‌های سراسری، ناوبری، اجزای مشترک، قالب اعداد، دسترس‌پذیری |
| `06_API_EXAMPLES.md` | نمونه درخواست و پاسخ JSON برای مسیرهای اصلی |
| `07_QA_CHECKLIST.md` | چک‌لیست پذیرش هر کار و انتشار |

## چه چیزی هنوز باز است

پالت/لوگو/toolkit، درگاه پرداخت، ارائه‌دهنده پیامک و نرخ، ماهانه پایه (۷۹۰ هزار؟) و سقف‌های پایه، سیاست proration و قواعد مالیاتی نهایی. فهرست کامل و اثر هر کدام: `docs/IMPLEMENTATION_GUIDE.md` §۹. ChatGPT باید با mock و پیکربندی جلو برود و هیچ‌کدام را «انجام‌شده» گزارش نکند.
