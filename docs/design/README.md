# طراحی UI طلاتا — بسته مرحله A (پیشنهادی)

**وضعیت: پیشنهادی، در انتظار تأیید مالک.** هیچ‌یک از رنگ‌ها، لوگوها، فونت یا toolkit این پوشه تأیید نشده‌اند. تصمیم‌های تأییدشده فقط در `UI_APPROVED_DECISIONS.md` ثبت می‌شوند.

املای فارسی برند طبق اعلام مالک: **طلاتا** (لاتین: Talata).

## قواعد این بسته

- همه قیمت‌ها نمونه‌اند و از مثال کاری Master Prompt گرفته شده‌اند (نرخ ۱۸ عیار ۱۰٬۰۰۰٬۰۰۰ تومان، ۲ گرم، اجرت ۲٪، سود ۵٪، مالیات ۱۰٪ روی اجرت و سود، جعبه هدیه ۲۰۰٬۰۰۰ تومان ← قابل پرداخت ۲۱٬۷۶۲٬۰۰۰ تومان). نرخ واقعی نیستند.
- جهت بصری انتخاب‌شده: «برگه معامله» (گزینه ۱ بریف کشف) با میان‌بر کوتاه به کارهای تکراری؛ دلیل در `STAGE_A_REVIEW_REQUEST.md`.
- هیچ کتابخانه، Skill یا وابستگی runtime نصب نشده است. اتود با HTML/CSS ساده ساخته شده.
- لوگوی موجودی در ریپو یافت نشد؛ هر دو گزینه از صفر و بدون الهام از برند فروشگاه قبلی طراحی شده‌اند.

## ادامه کار (مرحله B) فقط پس از تأیید

پس از ثبت تصمیم‌ها در `UI_APPROVED_DECISIONS.md`: راه‌اندازی اسکلت Inertia/Vue، توکن‌ها، اجزای مشترک (Button، Field، MoneyInput، WeightInput، PuritySelect، Status، InvoiceRow، TotalSummary، AppNavigation) و سپس صفحات به ترتیب جدول پرامپ اجرای سریع.
