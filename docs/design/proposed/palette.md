# پالت رنگ پیشنهادی طلاتا (تأیید نشده)

نسبت‌های کنتراست با فرمول WCAG 2.x از کدهای hex محاسبه شده‌اند (اسکریپت ساده luminance)؛ هدف متن عادی ≥ 4.5:1 و متن بزرگ ≥ 3:1. وضعیت‌ها همیشه همراه نوشته و نشانه هستند؛ سبز/قرمز به‌تنهایی معیار نیست. طلایی هرگز رنگ متن روی سفید نمی‌شود. فقط حالت روشن.
