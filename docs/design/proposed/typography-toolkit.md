## فونت: Vazirmatn

- مجوز: SIL Open Font License 1.1 (متن مجوز در `fonts/OFL.txt`). استفاده تجاری و self-host مجاز است.
- وزن‌ها: ۴۰۰ متن، ۵۰۰ برچسب و دکمه فرعی، ۷۰۰ عدد قیمت و اقدام اصلی. فایل متغیر یک فایل برای همه وزن‌ها.
- اندازه‌ها: پایه ۱۶px، کمکی حداقل ۱۴px، قیمت ۴۴px موبایل و ۶۴px دسکتاپ، ارقام هم‌عرض (`font-variant-numeric: tabular-nums`) در ستون مبلغ.
- حجم اندازه‌گیری‌شده (فایل‌های عمومی Google Fonts نسخه v16، دانلود 2026-10-05، فقط برای سنجش):

### برنامه self-host

1. دانلود نسخه رسمی از مخزن `rastikerdar/vazirmatn` با ثبت نسخه و hash.
2. ساخت زیرمجموعه با `pyftsubset`: فارسی/عربی + ارقام فارسی، عربی و لاتین + ASCII پایه + علائم ریال/تومان/درصد؛ حذف لاتین گسترده. انتظار زیر ۷۰ KiB؛ ادعا فقط پس از اندازه‌گیری.
3. `@font-face` با `font-display: swap`، preload فقط فایل فارسی، fallback `Tahoma, "Segoe UI", sans-serif` با `size-adjust` برای کاهش جابه‌جایی.
4. قرار دادن روی مسیر first-party با hash محتوا و کش طولانی؛ هیچ درخواست به Google Fonts در برنامه.
5. بررسی چاپ (shaping، ارقام فارسی) و ۲۰۰٪ بزرگ‌نمایی روی گوشی ضعیف.

جایگزین در صورت رد: Vazir یا Sahel (هر دو OFL، همان سازنده).

دو فایل زیرمجموعه عمومی در `fonts/` فقط برای نمایش اتود `preview.html` گذاشته شده‌اند و فایل نهایی برنامه نیستند.

## Toolkit: مسیر A — PrimeVue Unstyled + طراحی اختصاصی

- Stack: Laravel + Inertia + Vue 3 + TypeScript + Vite؛ یک toolkit اصلی، بدون پروژه Next.js جدا.
- دلیل: رفتار آماده و دسترس‌پذیر برای Select، Dialog، Toast، DataTable و اعتبارسنجی فرم با import تک‌کامپوننت و RTL مستند؛ حالت Unstyled ظاهر آماده را حذف می‌کند و توکن‌های طلاتا تنها منبع ظاهر می‌شوند.
- چه چیزهایی از کتابخانه نمی‌گیریم: Button، فیلد عددی با واحد، MoneyInput/WeightInput، PuritySelect، InvoiceRow، TotalSummary و نوار وضعیت نرخ اختصاصی و سبک نوشته می‌شوند تا بسته ورود/نرخ کوچک بماند.
- بودجه (قرارداد موجود): ورود و نرخ/شروع ≤ 150 KiB JS gzip و ≤ 300 KiB کل؛ فرم فاکتور ≤ 220/400 KiB؛ فاکتور عمومی سرور-رندر ≤ 20 KiB JS.
- شرط قفل‌شدن انتخاب: ساخت یک برش production (ورود + نرخ/شروع + فاکتور ترکیبی) و اندازه‌گیری با پروفایل A/B. رد بودجه = بازبینی با Reka UI (مسیر B) با همان معیار، نه نصب هم‌زمان چند کتابخانه.
- Impeccable فقط ابزار نقد/ساده‌سازی در زمان توسعه است و وابستگی مرورگر نمی‌شود. UI UX Pro Max حداکثر منبع کمکی.
- آیکون: SVG خطی انتخابی inline یا sprite محلی؛ بدون بسته آیکون کامل یا runtime آیکون خارجی.

هیچ عدد حجم یا سرعت برای کتابخانه‌ها در این مرحله اندازه‌گیری نشده است. نصب فقط پس از تأیید مالک، با ثبت نسخه و مجوز در `UI_APPROVED_DECISIONS.md`.
