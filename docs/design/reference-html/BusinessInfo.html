۱ مورد ناقص
برای صدور اولین فاکتور، نام، موبایل و آدرس کسب‌وکار لازم است. فاکتور در حال ساخت شما (۲ ردیف) حفظ شده و بعد از ذخیره به آن برمی‌گردید.
این اطلاعات روی فاکتور و صفحه بررسی اصالت نمایش داده می‌شود. شماره ورود شما و شماره مشتری‌ها جدا و خصوصی می‌مانند.
